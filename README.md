# Gerenciador de Torneios e Interclasses do IFPI

## Sobre o Projeto

O Gerenciador de Torneios e Interclasses do IFPI é um site desenvolvido para divulgar e organizar as competições esportivas e campeonatos de e-sports realizados entre as turmas do instituto.

O sistema reúne informações importantes sobre os jogos, equipes e classificações, facilitando o acompanhamento dos campeonatos pelos alunos e organizadores.

## Funcionalidades

### Início

 Exibição dos jogos.
 Placar das partidas.
 Regras das competições.

### Galeria

 Fotos dos eventos e equipes participantes.

### Turmas

Uma página para cada turma.
  Foto e logo da turma.

### Formulário

 Cadastro de participantes e equipes.

### Classificação

 Tabela de classificação das equipes.
 Tabela com os jogos e resultados.

## Tecnologias Utilizadas

HTML5
 CSS3
